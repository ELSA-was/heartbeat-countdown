# 《心跳倒计时》互动恋爱视觉小说

一档真人恋爱直播综艺为背景的多分支视觉小说。四位男主 + 一位隐藏角色，
114 个剧情节点、12 个结局，含直播弹幕、好感度、亲密夜与真相线。

## 在线游玩

https://elsa-was.github.io/heartbeat-countdown/

## 内容规模

- 剧情：114 节点 / 12 结局（全部可达，无软锁）
- 美术：118 张（角色立绘 30 + 背景 22 + CG 24 + UI/封面 14 等）
- 音频：29 个（17 首 BGM，90-150 秒无缝循环；12 个音效）

## 目录结构

```
index.html   入口页面（由 player.html 提供）
core.js      引擎核心
app.js       播放器逻辑
story.js     剧本数据
theme.css    样式
assets/      图片与音频资源
```

## 说明

本仓库为静态站部署版本，资源以独立文件形式加载。
另有一个内嵌全部资源的单文件离线版 `game.html`（约 304 MB），
因超出 GitHub 单文件 100 MB 限制未纳入仓库，可在本地 `example/dist/` 下找到，
双击即可离线运行。

本作包含明确的成人性描写，仅限 18 岁以上阅读。
